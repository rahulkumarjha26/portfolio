# Rahul Kumar Jha — Personal Portfolio

> Interactive personal portfolio for **Rahul Kumar Jha** (AI & Generative AI Engineer). Built with a horizontal card-deck architecture inspired by modern design engineering, featuring a live dithered scanline avatar, interactive project showcases, and a responsive experience.

## Live Domain
- **URL**: [https://rahuljha.co.in](https://rahuljha.co.in)

## Tech Stack
- **Structure**: Semantic HTML5 with horizontal card-deck architecture
- **Styling**: Vanilla CSS (CSS Grid, Flexbox, custom scrollbars, frosted-glass header backdrops, 3D perspective transforms)
- **Living Portrait**: Custom HTML5 Canvas 2D engine with micro-dither raster, color-popping foreground grading, subtle 3D mouse parallax, and soft cursor illumination
- **Client Logic**: Vanilla JavaScript with mouse drag-to-scroll and keyboard horizontal navigation

## Featured Production Systems
- **Threadmark**: Multi-agent insurance operations command center (6 specialized agents, verified deterministic tool execution, 86-case benchmark evaluation).
- **RetailGuard AI**: Real-time retail loss prevention & theft surveillance vision engine (YOLOv11 pose estimation, spatial concealment geometry, ViViT spatio-temporal video transformers).
